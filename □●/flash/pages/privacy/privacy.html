Last updated: [date]

This page is a web app that runs in your browser: it connects to your Squares & Circles module over USB, shows its firmware and apps and updates them. It sets no cookies and uses no analytics service; the only data that goes to us is the report of section 5. This policy says which data is processed when you use it, by whom and why.

2. Hosting on GitHub Pages

The page is hosted by GitHub Pages, a service of GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. More: What is GitHub Pages? (data collection), GitHub General Privacy Statement.

3. Content loaded from GitHub

Your browser loads the list of firmware versions, the apps, the loaders and the release notes directly from GitHub (api.github.com, raw.githubusercontent.com, files of the public repository eh2k/squares-and-circles). GitHub receives your IP address and the usual data of a web request. Legal basis and transfer to the USA as in section 2.

4. Your module

The page talks to your module over WebUSB, WebHID, WebSerial or Web MIDI, and only to a device you chose in your browser's dialog. It reads the module's serial number, type, firmware version, installed apps and settings and writes firmware, apps and settings to it. Apart from the report in section 5 these data stay in your browser.

5. Report when a module connects

When a module connects, the page sends its serial number, its type and its firmware version once to our server at eh2k.spdns.org, so that we can see how many modules use the page and with which firmware. 6. Stored in your browser

The page keeps in your browser's local storage the type of module you chose last and the serial number of the module connected last, so that it finds it again. They stay on your device; you can delete them at any time with the site data of your browser. Legal basis: § 25(2) No. 2 TDDDG, they are needed for the functions you use. The page sets no cookies.
