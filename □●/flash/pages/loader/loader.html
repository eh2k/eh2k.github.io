First installation

Install the S&C loader

A bare module gets the S&C loader once, here in the browser (Chrome or Edge). With the loader, or an older S&C firmware, on the module: connect it and update on Module.

1
Choose the module type
The loader is built for each type of module.
2
Connect the Teensy over USB
Directly to the computer, not over a passive hub.
3
Reset
Pick the Teensy in the browser's dialog. If no device is listed, the Teensy is likely in its flashing mode already: go on with step 4.
4
Flash the loader
Pick "HID 16C0:0478" in the browser's dialog. If no device is listed, press the button on the Teensy and click Flash again.
Make sure the Teensy Loader is not running in the background.
2
Connect the Patch SM in its ROM bootloader
Hold the BOOT button of the Daisy Patch SM while you plug in the USB cable (plugged in already: hold BOOT and press RESET). In a DSM0 the buttons are behind the panel: with the S&C firmware running and connected, the module goes there over USB.
3
Install the DSM0 bootloader
Pick "DFU in FS Mode" in the browser's dialog. It goes into the internal flash, in place of a Daisy bootloader; the Patch SM then waits for the loader. Windows needs the WinUSB driver for this device once (Zadig).
4
Flash the S&C loader
Pick "DSM0 Bootloader <id>" in the browser's dialog. While the bootloader waits, the MENU key (the round key left of the display) and the Patch SM's LED breathe, they are on while it writes and blink on an error. Later, with a module that does not start: hold MENU while it gets power, it then waits here again.
Files of your own, command line
Without the browser: dfu-util -a 0 -s 0x08000000:leave -D boot_SC_DSM0_<sha>.bin in the ROM bootloader. The loader then goes over the bootloader's HalfKay (step 4); an S&C firmware that runs takes it over its own DFU too (dfu-util -a 0 -s 0x90040000:leave -D loader_SC_DSM0_<sha>.bin). Linux needs udev rules for 0483:df11 and the bootloader (1209:0001, its hidraw node too).
5
Ready to update
The module starts with the splash screen and a blinking "Ready to Update". Connect it and install firmware and apps on Module.

Without WebHID: download the S&C loader hex file and flash it with the Teensy Loader.
