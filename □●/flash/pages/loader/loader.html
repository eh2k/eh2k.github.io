First installation

Install the S&C loader

A bare Teensy needs the S&C loader firmware first. This works in the browser (Chrome or Edge). With the loader, or an older S&C firmware, on the module: connect it and update on Module.

1
Choose the module type
The loader is built for each type of module.
2
Connect the Teensy over USB
Directly to the computer, not over a passive hub.
3
Reset
Pick the Teensy in the browser's dialog. If no device is listed, the Teensy is likely in its flashing mode already: go on with step 4.
4
Flash the loader
Pick "HID 16C0:0478" in the browser's dialog. If no device is listed, press the button on the Teensy and click Flash again.
Make sure the Teensy Loader is not running in the background.
2
Download the loader
The DSM0 takes the loader as a bin file over DFU, at 0x90040000: dfu-util -a 0 -s 0x90040000:leave -D <file>.
5
Ready to update
The module starts with the splash screen and a blinking "Ready to Update". Connect it and install firmware and apps on Module.

Without WebHID: download the S&C loader hex file and flash it with the Teensy Loader.
